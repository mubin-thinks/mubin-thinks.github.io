## Zinc, a Simple Image Processor
_Zinc_ is one of the first project I worked on. It is a
simple program to manipulate/edit an image. The project is
purely written in C.

Zinc was a naïve attempt on creating an image processor
as this project is quite broad and can be extended more and
more to create a working production-grade software. My
attempt contains only a handful of features. Such as:
Grayscale Conversion, Brightness Adjustment, Tint, Color
Inversion and more...

The program only works inside the command line through
arguments passed to the program from the shell. The output
image is written in the currently working directory(cwd).
